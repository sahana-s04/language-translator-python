# language-translator-python
A multilingual language translator built using Python and Google Translate API

## About
A desktop-based language translator built using Python.
The application allows users to enter text, select a
source language and a destination language, and view
the translated output.

## Technologies Used
- Python
- Tkinter
- Googletrans

## Features
- Source and destination language selection
- Text input and translated output
- Graphical user interface

## Installation
1. Install Python.
2. Install the required package:

   pip install -r requirements.txt

## How to Run
Run the following command:

python main.py

## Note
An active internet connection is required for translation.
Translation quality and language availability depend on
the translation service.
